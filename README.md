# FamilyLoop

FamilyLoop is a web app built with Django that helps families stay connected. Users can create family circles, join existing circles using an invite code, and manage circle members from their dashboard.

---

## What It Can Do

* **Create Family Circles**: Anyone can create a new family circle and automatically become its administrator.
* **Join with Invite Codes**: Users can join multiple family circles using unique invite codes.
* **Manage & Monitor Circles**: View each circle's member list, edit circle names, remove members (as an admin), or leave a circle anytime.
* **Location Sharing & Family Map *(Coming Soon)***: Toggle real-time location sharing and see active family members on a map.

---

## Built With

* **Backend**: Python & Django
* **Database**: PostgreSQL (Supabase)
* **Frontend**: HTML & CSS
